# 本地内容后台

桌面双击「Adelaide Roof Kind 本地后台」，或在本站source运行 `npm run editor:dev`。只监听127.0.0.1，默认端口4214；重复打开会复用本网站已运行服务，冲突端口自动顺延。

1. 搜索或选择页面；左侧为原版式预览，右侧为编辑区域。
2. 点选中文正文，或从「文字位置」选择标题、正文、FAQ、按钮文字、图片说明及SEO字段。
3. 修改后点「保存中文草稿」。关闭或重新打开仍可读取；「已保存历史」可恢复最近20次修订。
4. 「英文对照」只读。改好后在聊天告知助手：读取本站后台草稿，核对并同步英文。可用 `npm run editor:changes` 导出修改对照，不使用外部自动翻译。

草稿保存于本项目 `.local-editor/drafts`，不会自动修改正式英文HTML、中文词典、dist或线上网站。共享导航/页尾、联系方式、ABN及价格等业务事实不在普通文字编辑范围；图片、链接目标及版式修改交由助手处理。

保存只在本机，不是部署。英中同步核验、构建与用户明确授权之后，才可走GitHub→Vercel发布。本轮未发布。该后台是本机可信维护工具，不是公网多用户登录系统；不要把端口对外暴露。

启动失败可查看 `.local-editor/launcher/launcher.log`；源页面基线变化时旧草稿会拒绝覆盖，请联系助手合并。
